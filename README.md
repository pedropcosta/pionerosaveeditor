# Pionero Capital Save Game Editor

> [!NOTE]
> **Unofficial tool, created with Claude. for testing purposes only.** 
> Not affiliated with or endorsed by the developers of Pionero Capital. Editing your save can break it; always keep a backup and use at your own risk.

Open your `savegame.gz`, change the values and save a new copy. Everything happens on your computer; the file never leaves the browser.

## Features
###  Character
1. Personal Money
2. Experience
3. Skill/Permit Points
4. Permits

### Company
1. Company Money
2. Company Experience
3. Employees Skill Level
4. Employees Salary
5. Add Employees

### Vehicles
1. Repair Vehicles
2. Refuel Vehicles
3. Add Vehicles (Personal or Company)
